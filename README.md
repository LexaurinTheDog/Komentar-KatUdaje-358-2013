# Komentář k vyhlášce č. 358/2013 Sb., o poskytování údajů z katastru nemovitostí

Otevřený komentář k vyhlášce o poskytování údajů z katastru nemovitostí — § po §: doslovné znění, výklad, zmocnění a jeho meze, kazuistika, protiargumenty a praktický závěr; výpisy, opisy a kopie z katastru, dálkový přístup a webové služby, data v elektronické podobě, sledování změn a úplaty podle příloh.

Konsolidované znění: dokument e-Sbírky `SB-2013-00358_2024-07-01`.
